# MonitorLens

MonitorLens is an Auto-discovery and Machine-agnostic platform for real-time data processing and auto-scaling across Processor architectures.

With MonitorLens, you get a lightweight tool that stays out of your way.

**What you get**

- MonitorLens is an Auto-discovery and
- Machine-agnostic platform for real-time data
- processing and auto-scaling across Processor

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/MonitorLens.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure MonitorLens, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
